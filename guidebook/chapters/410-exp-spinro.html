Why you need this

Single-shot spin readout is the milestone that turns a charge device into a spin device: from here on, every experiment ends with "measure the spin". This chapter sets up energy-selective (Elzerman) and Pauli-blockade (PSB) readout with the 4x2 measuring the sensor and a DC-coupled AWG pulsing the plungers (Architecture A), then measures readout fidelity and the spin relaxation time \(T_1\). The physics is in Chapter 11.

Common building block: several readout windows per shot

Spin readout signals evolve during the read phase (a blip in Elzerman readout, relaxation in PSB). Recording the sensor in several consecutive windows per shot gives you a coarse trace of every shot with the efficient accumulated readout. In QICK tProc v2, every trigger() of a readout inside _body() is counted, and the returned data has one entry per trigger per shot :

class SpinReadout(AveragerProgramV2):
    def _initialize(self, cfg):
        self.declare_gen(ch=0, nqz=1)
        self.declare_readout(ch=0, length=cfg['win'])               # one window, e.g. 2 µs
        total = cfg['n_win'] * cfg['win'] + cfg['tof'] + 0.2
        self.add_pulse(ch=0, name='c', style='const', freq=cfg['f_ro'], ro_ch=0,
                       length=total, phase=0, gain=cfg['g_ro'])
        self.add_readoutconfig(ch=0, name='r', freq=cfg['f_ro'], gen_ch=0)
        self.send_readoutconfig(ch=0, name='r', t=0)
    def _body(self, cfg):
        self.trigger(pins=[1], t=0)                    # AWG: start the plunger sequence
        self.delay(cfg['t_read'])                      # AWG has reached the read level
        self.pulse(ch=0, name='c', t=0)                # one long readout carrier
        for k in range(cfg['n_win']):                  # unrolled at compile time
            self.trigger(ros=[0], t=cfg['tof'] + k * cfg['win'])

With 20 windows of 2 µs you get a 40 µs coarse trace per shot. Keep the number of unrolled triggers moderate (the tProc v2 program memory holds about 4096 instructions ). For long Elzerman reads (hundreds of µs to ms), use fewer, longer windows, or record whole traces with the DDR4 buffer.

Elzerman readout

Set-up

  1. Tunnel rates: from a telegraph-signal measurement (Chapter 39), set the dot–reservoir barrier so the tunnel time is 10–100 µs: slow enough for the sensor to resolve, fast compared with \(T_1\).
  2. Field: choose \(E_Z\) well above \(k_BT_e\) (Chapter 11), for example 0.4–0.6 T in silicon.
  3. Pulse: AWG plays empty → load → read → empty on the plunger (Figure 11.2), with the read level positioned so the Fermi level sits between \(E_\downarrow\) and \(E_\uparrow\).
  4. Find the read level: sweep the read-level voltage; the probability of a blip during the read window rises from zero (both levels below \(E_F\)), peaks where only spin-up can leave, and rises again to one when both levels are above \(E_F\) (any electron leaves). The plateau or peak between is the spin-selective window.

Analysis

For each shot, low-pass filter the window sequence and check whether the signal crosses a blip threshold in the read phase. The fraction of shots with a blip is \(P_\uparrow\) (with errors). Plot histograms of the maximum signal per shot for prepared states to choose the threshold; the spin-down histogram is a single peak, the spin-up histogram a peak at the blip level plus a tail of shots that relaxed before tunnelling.

T1

Load with both levels below \(E_F\) (random spin, roughly 50% up), wait a time \(\tau\) at that level, then read. The blip fraction decays as \(P_\uparrow(\tau) = A\,e^{-\tau/T_1} + B\). Repeat versus magnetic field: \(T_1\) falls steeply with field and dips at the spin–valley hot spot, which gives the valley splitting (Chapter 10) .

Pauli spin blockade readout

Set-up

  1. Find the \((1,1)\)–\((2,0)\) transition in a fast CSD (Chapter 40), in virtual coordinates.
  2. Sequence: (a) initialise in \(S(2,0)\) by waiting deep in \((2,0)\); (b) pulse into \((1,1)\) and wait long enough for the micromagnet field difference to mix \(S\) and \(T_0\) (tens of ns to µs), giving a mixed spin state; (c) pulse to a candidate readout point just across the interdot line into \((2,0)\); (d) read the sensor. As a reference, run the same sequence without the wait in \((1,1)\), so the state stays a singlet.
  3. Map the readout window: scan the readout point over a 2D region near the transition and plot the difference between the mixed and singlet-reference signals. The PSB triangle (Figure 11.4) is where they differ. spinQICK has routines for this (measurement-window and idle-cell scans) .
  4. Choose the integration window from single-shot data: separation grows with integration, but triplets relax to the singlet during readout (Chapter 11).
In the lab

HRL's spinQICK exchange-only work made every PSB measurement relative to a reference measurement immediately before each shot (initialise a singlet, measure at the readout window), to cancel slow drifts of the sensor. They reached SNR of 5–6 and a singlet assignment of 98.9% for prepared singlets . Reference measurements cost time but make long experiments robust against sensor drift.

Readout and initialisation fidelity

From histograms of prepared states, extract the overlap error and the relaxation tail. A common model fits each histogram with two Gaussians plus a "relaxation bridge" between them. Separate readout errors from initialisation errors by repeating readout twice in one shot (if the readout is non-destructive enough) or by preparing states with different methods. Report readout visibility and the conditions (integration time, field, temperature) clearly.

Real-time thresholding

For single-shot data, QICK's acquire(..., threshold=, angle=) classifies shots after rotating the IQ plane . For feedback (for example, re-initialising until the readout says "spin down"), the tProcessor reads the result and branches (Chapter 35). Elzerman readout has the useful property that after a spin-up blip a spin-down electron reloads the dot, so readout also re-initialises.

On the 4x2

In this chapter the 4x2 does the readout and triggers; the AWG does the plunger pulses. The accumulated buffer (16 384 entries per readout on the standard firmware) holds shots × windows; for 20 windows per shot that is 819 shots per buffer fill, which QICK reads out in chunks during long acquisitions . For millisecond Elzerman reads, the 1.94 s DDR4 buffer can record hundreds of complete shot traces in one go.

Check yourself

1. In an Elzerman read-level sweep, the blip probability is 0 at low read voltage, 0.4 in a middle range, and 1 at high voltage. What is happening in each range?

Show answer
Low: both spin levels below \(E_F\), no electron can leave. Middle: only spin-up above \(E_F\), so only spin-up electrons leave: spin-selective readout, with ~40% of loaded spins up (plus errors). High: both levels above \(E_F\), every electron leaves.

2. Why does PSB readout often use a reference measurement in every shot?

Show answer
The sensor's working point drifts (charge noise, temperature). Comparing each measurement with a reference taken moments earlier removes slow drifts, keeping the threshold valid over long experiments.
Summary
  • Record several readout windows per shot; QICK returns one value per trigger.
  • Elzerman: set tunnel rates and field, find the spin-selective read level, detect blips; measure \(T_1\) and its field dependence.
  • PSB: initialise S(2,0), mix in (1,1), pulse to the readout window, compare with a singlet reference; map the PSB triangle.
  • Extract fidelities from prepared-state histograms; threshold in software or in the tProcessor for feedback.
