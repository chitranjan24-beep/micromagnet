Why you need this

Research groups are judged by numbers like "99.9% single-qubit gate fidelity", "98% readout fidelity" or "two-qubit gate above the fault-tolerance threshold". To read those papers, and to produce such numbers yourself, you need to know what a gate set is, how gate errors and readout errors are separated, and how techniques like randomised benchmarking work. These experiments also put the hardest demands on your control electronics: long random pulse sequences, exact phase bookkeeping and many repetitions.

What a gate set is

A quantum computation is a sequence of gates. A small set of gates is universal if combinations of them can approximate any operation. A standard universal set is: arbitrary single-qubit rotations plus one entangling two-qubit gate such as CNOT or CZ.

In spin-qubit experiments the physical single-qubit gates are usually just two: X/2 and Y/2 (π/2 rotations about x and y), made with microwave bursts at phases 0° and 90°. All other single-qubit rotations are built from these plus Z rotations:

  • Virtual Z. A Z(θ) rotation is implemented by adding θ to the phase of every later drive pulse on that qubit. It costs no time and has no error. A Y/2 is then the same burst as X/2 with a phase shift, and an arbitrary rotation \(U = Z(\alpha)\,X/2\,Z(\beta)\,X/2\,Z(\gamma)\) needs only two physical pulses.
  • Composite sequences. X = X/2·X/2; Hadamard ≈ Y/2 followed by Z(π).

Fidelity: how close to perfect is "close"?

The fidelity between an ideal pure state \(\ket\psi\) and the actual state \(\rho\) is \(F = \bra\psi\rho\ket\psi\), the probability that the actual state would pass a test for being \(\ket\psi\). For a gate, the average gate fidelity averages this over all possible input states. The error per gate is \(r = 1 - F\).

A useful rule of thumb links gate error to coherence: during a gate of duration \(t_g\) the qubit dephases by roughly \(t_g/T_2\) (using the coherence time that applies during driving, which is often close to the echo \(T_2\) because driving itself refocuses slow noise). So

\[ r \sim \frac{t_g}{T_2} . \]
Worked example

A purified silicon qubit with \(T_2 \approx 50\ \mu\)s and an X/2 gate of 50 ns: \(r \sim 50\times10^{-9}/50\times10^{-6} = 10^{-3}\), so \(F \sim 99.9\%\). This matches the level reported in the best single-spin silicon experiments . A GaAs spin with \(T_2^* = 15\) ns and the same 50 ns gate would be hopeless without decoupling, which is why GaAs experiments relied on fast exchange-based singlet–triplet control.

Why do we care about 99% versus 99.9%? Because quantum error correction only works when the physical error per operation is below a threshold. For the widely studied surface code the threshold is around 1% per operation; operating well below it (0.1%) makes error correction efficient. Silicon spin qubits crossed 99% two-qubit fidelity in 2022 in three independent groups .

Measurement: readout fidelity and SPAM

Measurement in a spin-qubit device is indirect: the spin is converted to a charge state, the charge state changes a sensor's signal, and the signal is integrated over a readout window. Each shot gives one number (or an I/Q pair, Chapter 23). The shots from \(\ket 0\) and from \(\ket 1\) form two distributions, usually close to Gaussian, separated by some distance and each with a width set by noise.

Assign 0 below the threshold and 1 above. The two error probabilities are \(\epsilon_0 = P(\text{read }1\,|\,0)\) and \(\epsilon_1 = P(\text{read }0\,|\,1)\), and the readout fidelity is usually quoted as

\[ F_{\text{RO}} = 1 - \frac{\epsilon_0 + \epsilon_1}{2} \quad\text{or the visibility}\quad V = 1 - \epsilon_0 - \epsilon_1 . \]

For two Gaussians of equal width \(\sigma\) separated by \(\Delta\mu\), define the signal-to-noise ratio \(\text{SNR} = \Delta\mu/\sigma\). With the threshold in the middle, each error is \(\epsilon = \tfrac12\operatorname{erfc}\!\big(\text{SNR}/(2\sqrt2)\big)\).

Integrating longer improves SNR as \(\sqrt{t_{\text{int}}}\) for white noise, but the spin may relax during the window, so there is an optimum integration time. Chapter 23 shows how to choose it and how the FPGA computes it in real time. The spinQICK exchange-only work reports SNR values of 5–6 .

Initialisation is also imperfect. Errors in state preparation and measurement are lumped together as SPAM errors. They are why every curve in Chapter 4 needed a free amplitude and offset, and why gate characterisation methods are designed to be insensitive to them.

Calibration sequences: AllXY

Before measuring fidelities you need well-calibrated pulses. A favourite quick check is AllXY: 21 short sequences of two pulses each (for example XX, YY, XY, X/2 Y/2, …) chosen so that ideal results form a staircase of 0, ½ and 1. Each kind of error (wrong amplitude, wrong detuning, wrong phase between x and y) distorts the staircase in a characteristic way, so one glance tells you what to fix. spinQICK includes AllXY for single-spin qubits .

Randomised benchmarking

How do you measure a 0.1% gate error when readout errors are 2%? Randomised benchmarking (RB) solves this:

  1. Choose a random sequence of \(m\) gates from the Clifford group (24 operations for one qubit).
  2. Append the one Clifford that inverts the whole sequence, so that the ideal final state is \(\ket 0\).
  3. Measure the probability of getting 0. Average over many random sequences of the same length.
  4. Repeat for many lengths \(m\) and fit \(P(m) = A\,p^m + B\).

SPAM errors only affect \(A\) and \(B\), not the decay constant \(p\). Random sequences turn coherent errors into an average depolarising effect, so the decay is a clean exponential. The average error per Clifford is \(r = (1-p)(d-1)/d\), with \(d = 2\) for one qubit. If each Clifford is built from on average 1.875 physical X/2 or Y/2 pulses, the error per physical gate is about \(r/1.875\).

Variants you will see in papers: interleaved RB (insert one specific gate between random Cliffords to measure that gate's error), two-qubit RB (Cliffords on two qubits, much longer sequences), and gate set tomography (GST), which reconstructs the full error model of every gate and was used in several of the 2022 silicon threshold papers .

On the 4x2

RB is a demanding test of a controller. You need hundreds of different random sequences, each up to hundreds of gates long, with exact phase tracking. With QICK, two strategies work:

  • Compile each random sequence into its own short QICK program and run them one after another from Python. Simple, but loading many programs adds overhead.
  • Store the Clifford pulses once and let the tProcessor select them in a loop from a table in data memory. tProc v2 programs are limited to about 4096 instructions , so long sequences must be built with loops and table look-ups rather than written out.

Virtual Z gates are implemented in QICK by changing the phase parameter of following pulses, which costs no time.

Summary
  • Spin qubits typically use physical X/2 and Y/2 pulses, virtual Z gates, and an exchange-based CZ or CROT as the entangling gate.
  • Gate error scales roughly as gate time over coherence time; 1% is the surface-code threshold scale, silicon spins have reached 99.9% (one qubit) and over 99% (two qubits).
  • Readout fidelity follows from histogram overlap; SNR 6 gives about 0.1% error per state.
  • AllXY diagnoses calibration errors; randomised benchmarking measures gate errors independent of SPAM.
